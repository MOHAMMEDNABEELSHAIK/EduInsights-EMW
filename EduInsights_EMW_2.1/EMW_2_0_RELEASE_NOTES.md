# EduInsights EMW 2.0 — Release Notes

## Added
- Multi-role self-registration: Analyst, Student and Parent. Student/Parent accounts link to a learner ID.
- Parent/Student Portal: read-only profile, attendance, score, engagement, project count and suggested follow-up for the linked demo learner.
- AI Recommendations: transparent rule-based next-step suggestions using attendance, score, engagement and project completion.
- Notifications: in-app review list for attendance, learning-support signals and pending/part-paid demo fees.
- Reports: multi-sheet Excel workbook and PDF summary downloads, alongside existing CSV exports.

## Important limitations
- The bundled records are synthetic. Do not add identifiable data about children.
- Student/Parent linking is based on a typed learner ID and is not verified. This is not a production family portal.
- Notifications are in-app only; no email, SMS or push delivery is configured.
- Recommendations are simple explainable rules, not a validated AI model. A mentor must review every suggestion.
- Authentication is a prototype. Production use requires verified identity, account approval, strong security controls, privacy review, backups and audit logging.
